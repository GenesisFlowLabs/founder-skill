# founder-marketing

Resolve this loaded skill directory with `pwd -P`, set `SKILL_DIR` and parent `PACK_DIR`, and read `"$PACK_DIR/founder/policy.md"` plus the relevant `profiles.md` section. Use authorized `RUN`; financial records stay in the local finance workspace.

1. Read actual buyer interviews, purchase/usage evidence, current offer, competitor research and existing campaign records. Separate user, champion, budget owner and procurement reviewer. Select an audience from observed need and reachability; simulated buy rates cannot rank real segments.
2. Draft one positioning line: for whom, which workflow/outcome, why it matters and what substantiates the difference. Preserve product names and current capability boundaries. If evidence is thin, label this a positioning hypothesis.
3. Select the smallest useful channel experiment using evidence of where this audience pays attention. B2B options may include existing relationships, partner referrals, targeted discovery, relevant communities and search. Research current platform costs/rules if reporting them. Do not invent acquisition costs, a budget or a channel's performance.
4. Draft messages addressing sourced objections and the actual outcome. Identify the source of each claim. Simulated comments may guide wording but are never testimonials. Do not invent customer logos, savings, reviews, follower counts or promised results.
5. Define the hypothesis, target audience, proposed dates, owner, allowed spend, measurement and decision condition. Use actual acquisition/delivery economics only when available; no lifetime value or CAC allowance derived from panel purchases. If budget is unknown, propose an uncosted draft or a no-spend research step.

Return positioning, the small experiment, draft assets, evidence limits and one next action in the requested format; use `marketing.md` only if a separate artifact is needed. Use a content calendar only when requested or justified, with proposed dates clearly labeled. All email remains draft-only, with contact-card verification. Publishing, outreach, ads and spending require authorization for that specific action; preparing this plan does not grant it.
