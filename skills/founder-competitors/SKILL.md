# founder-competitors

Resolve this loaded skill's directory with `pwd -P`, set `SKILL_DIR` and its parent `PACK_DIR`, and read `"$PACK_DIR/founder/policy.md"` plus the relevant `profiles.md` section. Use the authorized `RUN` workspace.

1. Read the current buyer/workflow brief. For B2B include users, budget owner, buying trigger and approval path. Existing spreadsheets, manual work, internal development and doing nothing are alternatives too.
2. Research the nearest direct competitors, indirect solutions and workarounds using current public primary pages. Use lightweight reads. Record scope, observation date and unavailable pages. Do not imply exhaustive coverage or infer a price from an inaccessible quote-only page.
3. Structure comparison evidence as `name,type,url,buyer,workflow,comparable_price,price_basis,source_date,unknowns`; use `competitors.csv` only if a separate table is needed. Match currency, contract period, included services, setup/support and minimum commitments. Keep private interviews in their authorized source location.
4. Review relevant published customer feedback. Record sample size and selection limits. Quote briefly with attribution; counts refer only to inspected records. Separate a complaint from your inferred opportunity.
5. Return the alternatives table, evidenced differences, switching/procurement constraints, and a possible gap to test in the requested format; use `competitors.md` only if a separate artifact is needed. Say when evidence does not support a gap. Compare prices only when their units and terms match.

End with one interview or research action that could change the recommendation. A possible gap is a hypothesis; competitor presence, reviews and website claims do not establish demand for this offer. Route to offer or pricing only where needed.
