# founder-offer

Resolve this loaded skill directory with `pwd -P`, set `SKILL_DIR` and parent `PACK_DIR`, and read `"$PACK_DIR/founder/policy.md"` plus the relevant `profiles.md` section. Use the authorized `RUN` workspace.

1. Read the existing offer, current workflow evidence, interviews, delivery limits and agreed terms. Preserve existing company/product names. Use the Offers framework from `"$PACK_DIR/founder-board/lenses.md"` as an analytical lens without impersonating or implying author endorsement.
2. Separate the user doing the work from the buyer approving it. Identify the trigger, current workaround, desired result, switching constraints and acceptance condition. Mark unsourced buyer needs as hypotheses.
3. Build only enough scope to achieve that result. State included work, exclusions, customer inputs, owner, dependencies, implementation/support expectations and how completion is recognized. Distinguish proposed capabilities from shipped ones.
4. Map documented objections to an appropriate response or explicit open question. Label simulated objections separately. Extra features, bonuses and guarantees need a delivery reason and sourced cost assumptions. Use founder-cfo privately for any financial assessment; leave unknown economics unresolved.
5. Price the outcome or fixed scoping result. Show unresolved terms rather than inventing a fee, discount, guarantee, deadline or capacity claim. A proposal is not an agreement.

Return the proposed outcome, scope, terms, evidence and one next action in the requested format: normally a real buyer conversation or a bounded paid pilot definition. Use `offer.md` only if a separate artifact is needed. If a revised pitch is requested or needed downstream, update `pitch.md` as a labeled new draft while preserving the prior version.

An optional simulated retest uses a new panel directory for changed pitch/profile/settings. Keeping the seed comparable does not permit reusing old answers. Describe differences as synthetic observations, never demand lift. Do not require simulation before moving forward with stronger real evidence.
