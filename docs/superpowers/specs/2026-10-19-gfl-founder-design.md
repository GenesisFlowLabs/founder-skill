# Maintained founder skills for GFL

The user authorized autonomous analysis, adaptation, installation, and bounded parallel work after the fork was created. They want one maintained source and careful computer resource use. Earlier review found missing costs silently becoming zero, an overconfident profitability verdict, and stale panel answers surviving a changed pitch.

## Selected approach

Keep one Git repository owned by GenesisFlowLabs. Add one `founder` entry point that selects the smallest relevant workflow among the existing eleven specialist skills. Install linked skill folders from the canonical checkout for Claude Code and Codex, so edits happen in our code. Keep upstream available for manual fetching. No additional services or dependencies.

## Required behavior

- Financial inputs must explicitly provide cost arrays; an explicit empty array represents confirmed zero. Reject missing, nonnumeric, nonfinite, or invalid negative values. Missing inputs produce Incomplete in the plan. Results are projections, never proof of profitability or demand. Simulated buyer rates never validate demand or gate a financial verdict.
- Panel runs must not silently mix pitches, personas, or settings. Resume identical runs; require a new run directory for changed input. Default to a small panel and at most two simultaneous buyer agents. B2B cards represent organizational purchasing roles and budgets, not personal income. Preserve original retail support.
- Skills use current evidence, outcome pricing, US spelling, existing product names and trackers, and no fabricated claims. Financial/private data stays in its authorized local workspace and out of git. Publishing and communications remain within user authorization; email remains draft-only. Do not auto-start browsers, local models, MCP servers, or agent CLIs.
- One router plus eleven specialists, each independently usable. Native Claude paths and Codex paths must resolve supporting files without copied implementations. Commands use explicit interpreters.
- Installer must preflight all destinations, refuse unrelated conflicts, be idempotent, support dry-run/check/uninstall of only its own links, and record its canonical source. No symlinks to temporary worktrees in the final install.
- Keep the MIT attribution. Public repository contains reusable code and synthetic tests only. Private business briefs stay outside it.

## Scope boundary

This release is a decision aid, not autonomous outbound marketing, accounting software, a compliance certification, or a full subscription cohort model. Use explicit monthly unit assumptions for client-month projections, and mark retention/churn forecasts unsupported without a separate model. Deliver one evidence-backed exercise for GFL and Panora, with open decisions preserved rather than invented.

## Resource envelope

At most three worker agents beside the integrator, with no nested agents from workers. Python checks are small and sequential within each lane. No 100-buyer run. No new local browser, Docker container, or model. Only close processes or tabs created for this task. Review memory pressure before external tools.
